# QuickNotes App

QuickNotes is a simple note-taking web application that allows users to create, organize, search, and delete notes. Notes are categorized and stored in the browser using localStorage, so they remain available after refreshing the page.

## Features

- Create notes
- Categorize notes as Personal, Work, or Study
- Search notes
- Delete notes
- Validate notes between 1 and 200 characters
- Display the number of notes
- Save notes using localStorage
- Responsive design for mobile devices
